# mirth-lab
Built a production-oriented healthcare interoperability laboratory with Mirth Connect, Docker and PostgreSQL. Implemented inbound and outbound HL7 v2 ADT, SIU, ORM and ORU workflows; dynamic OBX transformation; MLLP acknowledgment validation; queue recovery; AE/AR handling; controlled reprocessing; and ORU-to-FHIR R4 transaction mapping.
